# ADR 0003：确定性引擎边界

- 状态：Accepted
- 日期：2026-07-26

## 背景

重放、解释、反事实比较、求解和谜题验证都依赖同一规则输入产生一致结果。如果模拟实现混入 React 状态、
网络、数据库、时间或 Cloudflare runtime，结果将难以复现和审计。

## 决策

未来模拟引擎必须是独立、纯 TypeScript、无框架依赖、确定性的 package。它接收显式版本、状态、规则、
种子和预算，返回新状态与结构化轨迹。不得读取系统时间、隐式随机数、网络、DOM、文件系统或平台绑定。

## 结果

Web 和 Worker 可以调用同一权威实现，解释从真实执行轨迹产生，重放可做确定性测试。代价是所有非确定性
来源都必须显式建模，格式演化必须版本化。该 ADR 只定义未来边界；Milestone 1 不创建 Engine 占位代码。
