# 产品宪章

## 产品愿景

Axiom Garden（公理花园）是一座面向抽象规则世界的可视化实验室。它让创作者用安全、受限、可验证的
规则构造世界，运行并回放演化，理解结果为何发生，再将世界改造成可分享和 Remix 的谜题。

## 核心用户

- 喜欢逻辑系统、自动机和涌现现象的创作者
- 希望制作规则型谜题但不想编写任意代码的设计者
- 希望观察、解释和比较确定性系统的学习者

## 主要使用场景

- 通过可视化规则搭建抽象几何世界
- 运行、暂停、单步和回放世界状态
- 追踪触发规则，解释某个结果的因果链
- 创建反事实分支并比较差异
- 从规则世界形成可验证、可评分的谜题

这些场景描述目标方向，不代表 Milestone 1 已实现。

## 非目标

- 通用编程 IDE 或任意代码执行环境
- 现实政治、宗教、族群、暴力或生命体模拟
- 赌博、诱导消费、社交聊天或攻击性工具
- 用大语言模型替代确定性规则引擎
- 在 Milestone 1 提供账户、数据库、协作或正式部署

## 内容安全边界

产品世界只使用抽象、非生命的几何符号、颜色、数字和中性材质。禁止政治、宗教、种族、暴力、血腥、
仇恨、成人、赌博、违法、对未成年人有害、攻击人类或网站/网络的内容。规则语言永远不得执行用户提供的
JavaScript、Wasm、shell 或其他任意代码。

初期不接入任何 LLM。未来若引入，只允许 DeepSeek API，且其输出不得成为规则执行结果的权威来源。

## 成功指标

以下是未来需要验证的指标，不是已达成数据：

- 新用户能在有限时间内理解“规则 → 执行 → 解释”的核心循环
- 相同版本、种子与输入能得到字节级可比较的确定性结果
- 创建者能在不写任意代码的前提下表达有趣规则
- 解释与重放能帮助用户定位结果来源
- 谜题能够通过自动验证避免无解或错误答案
- 安全内容和执行边界可测试、可审计

## 产品原则

1. 确定性优先于魔法感。
2. 解释是核心产品能力，不是附加日志。
3. 创作自由必须位于安全、受限的表达系统内。
4. 抽象视觉服务于规则理解，不制造刺激和噪声。
5. 版本化格式和重放能力先于云端规模。
6. 每个正式能力都通过整数 Milestone 引入。

## 创新假设

本产品不声称“全球绝无同类”。创新假设是：将可视化受限规则语言、确定性执行、逐步解释、反事实比较、
谜题生成与 Remix 谱系组合在同一工作流中，会形成有差异化价值的创作与学习体验。该假设需要通过用户
研究和实际使用验证。

## 风险与控制

| 风险                   | 控制                                           |
| ---------------------- | ---------------------------------------------- |
| 规则表达力导致任意执行 | 封闭 DSL、白名单 AST、资源配额、无 eval        |
| 引擎结果不可重放       | 纯 TypeScript 确定性引擎、版本化格式、重放测试 |
| 解释与真实执行不一致   | 解释直接消费引擎产生的结构化轨迹               |
| 状态空间爆炸           | 明确步数/节点/时间预算，渐进式分析             |
| 用户生成内容越界       | 输入验证、内容政策、报告与审核规划             |
| 依赖与供应链风险       | lockfile、自动 CI、依赖审计与最小依赖面        |
| 云平台耦合核心逻辑     | Engine 不依赖 Web 框架或 Cloudflare runtime    |
