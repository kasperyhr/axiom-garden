# 正式 Milestone

1. **产品宪章与 Monorepo 骨架（已完成）**：建立边界、文档、最小 Web/Worker、共享契约和 CI。
2. **设计系统与应用壳（已完成）**：建立主题、组件、导航、响应式 App Shell 与浏览器验收基础。
3. **领域模型与版本化格式（已完成）**：定义世界文档的最小领域对象和可迁移格式。
4. **确定性模拟器最小内核（已完成）**：实现无框架依赖的确定性状态步进。
5. **基础网格渲染器（已完成）**：只读呈现抽象网格、符号与状态。
6. **元素工具箱与世界编辑（已完成）**：放置和编辑允许的抽象元素。
7. **规则 DSL 规范**：定义安全、受限、不执行任意代码的规则语言。
8. **规则 AST 与验证器**：解析、版本化并验证白名单 AST。
9. **基础条件系统**：表达受限的邻域、状态和数值条件。
10. **基础动作系统**：表达受限、确定性的状态变更动作。
11. **规则冲突解析**：定义多规则同时命中的稳定优先级和合并语义。
12. **可视化规则编辑器**：以可访问 UI 组合合法规则。
13. **时间轴与执行控制**：提供运行、暂停、单步和速度控制。
14. **完整重放系统**：保存并确定性重现执行轨迹。
15. **规则触发轨迹**：记录每步命中的规则和作用目标。
16. **解释面板**：以执行证据说明状态变化原因。
17. **反事实分支**：从历史步骤派生替代输入或规则分支。
18. **双世界差异比较器**：可视化比较两条分支的状态和轨迹差异。
19. **目标条件与失败条件**：声明并判定谜题成功和失败。
20. **谜题游玩模式**：提供受约束的解谜交互和重置流程。
21. **解题记录与评分**：记录可验证操作并根据明确指标评分。
22. **基础状态空间搜索**：在资源预算内探索可达状态。
23. **唯一解验证**：检查谜题是否存在且仅存在目标意义下的唯一解。
24. **难度分析器**：以搜索和行为指标估计难度。
25. **自动谜题生成器**：在安全预算内生成候选谜题并验证。
26. **提示生成器**：基于可验证搜索证据给出分级提示。
27. **循环与稳定状态检测**：识别周期、静止和重复状态。
28. **不变量候选发现**：发现并验证可能保持不变的量。
29. **不可达性分析**：为目标不可达提供可检查的分析证据。
30. **规则质量检查器**：检测冲突、死规则、歧义和性能风险。
31. **本地作品库**：在设备本地保存、组织和迁移作品。
32. **账户与身份系统**：引入最小身份、会话和权限边界。
33. **云端作品与版本历史**：安全存储作品和可恢复版本。
34. **分享与 Remix 谱系**：分享只读作品并记录派生关系。
35. **实时协作编辑**：支持有冲突策略的多人同步编辑。
36. **生产发布与稳定性验收**：完成部署、安全、性能、恢复与发布验收。

## 版本规则

- 正式产品功能只能通过整数 Milestone 增加。
- `1.1`、`1.2` 等小数 Milestone 只能修复对应整数 Milestone 已有范围内的问题。
- 小数 Milestone 不得新增产品功能或偷跑后续范围。
- 正式整数 Milestone 总数不得超过 50；新增或调整必须记录原因和依赖关系。

Milestone 6 只完成内存 Editor、纯数据命令、元素工具箱、Canvas 编辑、Inspector 和 Undo/Redo；Milestone 7 的规则 DSL 规范尚未开始。
